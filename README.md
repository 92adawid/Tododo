# 📅 Kalenderverktyg i JavaScript

Ett webbaserat verktyg där användaren kan skapa, schemalägga och hantera todos kopplade till en interaktiv kalender.

> Fyll i era namn här

## 📖 Om projektet

Verktyget visar en todo-lista till vänster och en månadskalender till höger. Varje todo är kopplad till ett specifikt datum och syns i kalendern som en siffra per dag. Projektet är byggt med vanilla JavaScript och tränar på att arbeta med Git och GitHub i projektform.

## ✨ Funktioner

- Lägg till och ta bort todos kopplade till ett datum
- Välkomstsegment med aktuell tid, veckodag och datum
- Månadskalender med antal todos per dag
- Navigera mellan månader
- Svenska helgdagar visas i kalendern
- Responsiv design ned till 375px bredd

## 🗂️ Projektstruktur

```
/
├── index.html
├── style.css
├── main.js          # Startpunkt – initierar applikationen
├── todos.js         # Hantering av todos (lägg till, ta bort, spara)
├── calendar.js      # Kalenderlogik och rendering
└── today.js         # Välkomstsegment med tid och datum
```
